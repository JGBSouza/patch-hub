Introdução

Este relatório descreve as atividades planejadas para a disciplina MAC0214, relacionadas à contribuição em um projeto de software livre, o patch-hub, cujo objetivo é fornecer uma interface em modo texto (TUI) para visualização e manipulação de patches enviados ao kernel Linux.

O foco principal do trabalho é ajudar a estabilizar o patch-hub como software livre, destacando a importância de processos bem descritos (melhoria da documentação e comentários em códigos) e maior segurança de código para atrair e manter novos contribuidores.

Escopo das Contribuições

Melhorias de documentação e processos

  • #151 – Add excerpt CONTRIBUTING.md about rewriting branches for PRs
  • #136 – Fix table of contents of CONTRIBUTING.md
  • #133 – Add small excerpt about scope and breaking changes of Conventional Commits to CONTRIBUTING.md
  • #117 – Update README "Features" section
  • #93 – Update README demo GIF

Análise e adição de comentários em código

  • #8 – Add code documentation

Melhoria da cobertura de testes e QA

  • #140 – Improve Test Coverage and Quality Assurance

Atualmente o projeto possui apenas cerca de 15% de cobertura de testes. A expansão dessa cobertura é essencial para garantir confiabilidade, segurança do código e estabilidade contínua do projeto.

Conclusão

O trabalho tem como objetivo consolidar o patch-hub como software livre através da melhoria e aumento da documentação, padronizando processos e expandindo a cobertura de testes. Isso contribui para a atratividade do projeto, facilitando futuras colaborações e a qualidade do software como um todo.
